# Herbie

A controller for managing AI loops.

## Getting started

Requires Node.js 24 or newer and pnpm.

```sh
pnpm install
pnpm start
```

Prints `Hello, world!` immediately on startup, then every five minutes.
Press Ctrl+C to stop.

## Development

```sh
pnpm typecheck
pnpm build
node dist/index.js
```
