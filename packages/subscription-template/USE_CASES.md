## Decisions and limits

- Package: `packages/subscription-template`; isolated `feat/subscription-template` branch. Existing controller and agent-factory source/deployment are untouched.
- Better Auth owns accounts, sessions, passwords, MFA, passkeys and OAuth. Supabase supplies Postgres only: no parallel Supabase Auth identities or client service-role keys.
- Local Worker/Chromium are available. Docker Hub pull is rate-limited and the public ECR mirror is forbidden here; local Supabase CLI cannot create its home directory. PGlite provides actual Postgres SQL over the pg wire protocol for local fallback coverage. Native PostgreSQL 18.4 binaries from @embedded-postgres/linux-x64 now run locally on port 55433 and pass the team tests; PGlite is unsuitable for concurrent sessions. CI will use ordinary Postgres; Supabase service/hosted contracts remain explicitly unverified until runnable.
- Test email goes to a loopback-only inbox; it is not evidence of real email delivery. Provider secrets are absent. Isolated template hosting is authorized; paid provisioning, new credentials and live payments remain unapproved. Hosted Supabase provisioning awaits the required organization/cost confirmation.
- ChatGPT website identity is officially documented, but registration is partner-gated: https://developers.openai.com/siwc/request-client-id . OAuth adapters remain disabled without supplied credentials.
- Strict TypeScript and Oxlint forbid explicit/implicit `any` and suppression comments; use Zod narrowing, not type assertions, for external data.
